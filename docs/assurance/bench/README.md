# DMA bench kit

Everything needed to verify the port's DMA paths on real boards, ready before any board is on the desk: two bench
apps, the procedure with wiring figures, a fixed evidence form and the folder the filled forms go to. Nothing here
simulates hardware; the host side is covered by the conformance suite ([DMA](../../dma.md#conformance)).

| Part | Where |
| --- | --- |
| Bench apps (ESP-IDF projects, built in CI for esp32c6, esp32s3 and esp32) | `tests/target/dma/` |
| Procedure, boards, wiring, items and their hardware | [procedure-esp32.md](procedure-esp32.md) |
| Evidence form (copy one per run) | [evidence-form.md](evidence-form.md) |
| Filled forms | `docs/assurance/bench/runs/<yyyy-mm-dd>-<board>.md` |
| Wiring figures (generated by `tools/bench_wiring.py`) | `docs/assurance/bench/figures/` |

## The apps

| App | Items | Boards |
| --- | --- | --- |
| `dma_spi_bench` | SPI-START, SPI-5B (T8 on the ESP32), SPI-1028, SPI-UNALIGNED, SPI-PSRAM, SPI-ZEROCOPY, SPI-HEAP, SPI-LATE, SPI-GDMA | ESP32-C6, ESP32-S3, ESP32 |
| `dma_adc_bench` | ADC-START, ADC-RATE, ADC-DATA, ADC-ISR, ADC-HEAP, ADC-BLOCKED, ADC-NVS, ADC-STALL, ADC-SHAPE | ESP32-C6, ESP32-S3 |

Each app prints a run header and one line per item, then a summary:

```text
KB-BENCH-RUN app=dma_spi_bench target=esp32c6 chip_model=13 revision=0.1 cores=1 idf=v5.5.6 cpu_hz=160000000 tick_hz=1000
KB-BENCH SPI-5B PASS bytes=5 mismatches=0 canary=intact
KB-BENCH SPI-PSRAM SKIP reason=no-psram
KB-BENCH SUMMARY app=dma_spi_bench pass=8 fail=0
```

`PASS` and `FAIL` are the app's own judgement against the expected value in the procedure; `SKIP` means the board
lacks what the item needs. The evidence form records every line as it was printed, with the log file.

## Build and flash

```bash
cd tests/target/dma
idf.py set-target esp32c6
idf.py -DAPP_TYPE=dma_spi_bench -DAPP_SOURCE_FILE=dma_spi_bench.cpp build flash monitor
idf.py -DAPP_TYPE=dma_adc_bench -DAPP_SOURCE_FILE=dma_adc_bench.cpp build flash monitor
```

The ADC app is built with `sdkconfig.adc` on top of `sdkconfig.defaults` (`CONFIG_ADC_CONTINUOUS_ISR_IRAM_SAFE`,
`CONFIG_ESP_TIMER_IN_IRAM`), because it writes NVS while streaming.
